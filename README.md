# DryLeaf Technologies Website

Welcome to the official repository for **DryLeaf Technologies** — a modern, responsive, nature-tech web development & digital solutions company based in Coimbatore, Tamil Nadu, India.

![DryLeaf Technologies Logo](assets/images/DLT%20Logo.png)

## 🌐 Live Web Pages

- **Home Page**: `index.html` — Turning Ideas Into Digital Experiences
- **Services Page**: `services.html` — Web Development, E-Commerce, Custom Web Apps & UI/UX Design
- **About Us Page**: `about.html` — Company Mission, Vision, Core Values & Location Details

---

## 🎨 Visual System & Theme

- **Dominant Color**: Very Light Green (`#F1F8F1`)
- **Accent Fill**: Soft Green (`#E4F1E5`) & Crisp White (`#FFFFFF`)
- **Primary CTA Color**: Dry Leaf Orange (`#D97924`)
- **Typography & Dark Contrast**: Forest Green (`#164F3D`) & Dark Text (`#17332B`)

---

## 🛠️ Technology Stack

- **Markup & Semantics**: Pure HTML5 with SEO meta tags & Open Graph social cards
- **Styling & Layout**: Vanilla CSS3 with CSS Grid, Flexbox, Custom Design Tokens & `clamp()` fluid typography
- **Interactions**: Lightweight Vanilla JavaScript (No heavy frameworks or libraries)
- **Structured Data**: Schema.org JSON-LD for Search Engines
- **Search Engine Crawl Files**: `robots.txt` and `sitemap.xml`

## 🚀 How to Run Locally

Open `index.html` directly in any standard web browser or run a simple local HTTP server:

```bash
# Python HTTP Server
python -m http.server 8080
```
Then navigate to `http://localhost:8080/`.
